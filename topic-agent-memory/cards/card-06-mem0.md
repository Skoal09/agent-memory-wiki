# card-06：Mem0 / Mem0^g (2025) 證據卡

- **Wiki 來源**：`wiki/papers/mem0-2025.md`, `wiki/entities/mem0.md`
- **發表出處**：**arXiv Preprint (Apr 2025)**（`arXiv:2504.19413`，業界生產級長記憶系統基準研究）。
- **給初學者的一句話比喻**：把又長又雜的聊天紀錄提煉成一本「會自動塗掉過時資訊的精簡重點簿」（`Mem0`），需要追蹤跨時間人際或狀態演變時再外掛「標註作廢而非撕頁的關係白板」（`Mem0^g`）。
- **核心機制** [Mem0 2025, Sec. 2.1, Sec. 2.2]：
  - **基礎版 `Mem0`（萃取＋增量更新）**：結合非同步全域摘要 `S` 與最近 `m=10` 句對話抽出候選事實；再撈出 `s=10` 筆相近舊記憶，由 LLM 透過 Tool Call 決策執行 `ADD`、`UPDATE`、`DELETE`（刪除矛盾舊事實）或 `NOOP`。
  - **圖增強版 `Mem0^g`（Neo4j 圖譜）**：抽取實體節點與關係三元組 `(v_s, r, v_d)`，遇矛盾時將舊關係標記為失效（obsolete/invalid）而非物理刪除，保留時間軸推理能力。
- **關鍵實驗數據（LOCOMO 排除 Adversarial 題組，採 10 次 LLM-as-a-Judge `J`）** [Mem0 2025, Abstract, Sec. 3.1–3.2, Sec. 4.1–4.5, Table 1, Table 2]：
  - **整體準確率 `J`**：`Mem0` 達 `66.88 ± 0.15%`，`Mem0^g` 達 `68.44 ± 0.17%`（較基礎版高約 `2%`，比 OpenAI 內建記憶 `52.90%` 相對高出 `26%`，勝過固定切塊 RAG 最佳值 `60.97%`；對照 `Full-Context` 為 `72.90%`）。
  - **時間推理（Temporal `J`）**：`Mem0^g` 達 `58.13 ± 0.44`（優於 `Mem0` 的 `55.51`、Zep 的 `49.31`、OpenAI 的 `21.71`）。
  - **成本與延遲突破**：相較 `Full-Context`（`26,031` tokens、總 p95 延遲 `17.117` 秒），`Mem0` 每次僅檢索 `1,764` tokens（節省超過 **`90%`** Token 成本），總 p95 延遲降至 `1.440` 秒（降低 **`91%` 以上**；檢索僅 `0.200` 秒）。
  - **圖記憶代價與反直覺差異**：`Mem0` 建庫每對話約 `7k` tokens、`Mem0^g` 約 `14k` tokens（皆於 1 分鐘內可查；對比 Zep 約 `600k` tokens 且非同步建圖需數小時）。但在 Single-Hop（`65.71` vs `67.13`）與 Multi-Hop（`47.19` vs `51.15`）上，`Mem0^g` 反而不如純自然語言的 `Mem0`，總 p95 延遲也增至 `2.590` 秒。
- **適用前提**：尚未經同儕審查；若產品只需要單純快速個人回憶，用基礎 `Mem0` 比開啟圖記憶更快更準。
